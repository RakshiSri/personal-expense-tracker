# Personal Expense Tracker 💰

## Project Overview
Personal Expense Tracker is a Python-based web application that helps users manage and monitor their daily expenses.

## Features
- Add new expenses
- View all transactions
- Calculate total expenses
- Categorize expenses
- Delete unwanted expenses
- Visualize spending through charts
- Store records using SQLite database

## Technologies Used
- Python
- SQLite
- Streamlit
- Pandas

## Installation and Setup

1. Clone or download this project.
2. Install the required libraries:

```bash
pip install streamlit pandas
```

3. Run the application:

```bash
streamlit run app.py
```

4. Open the local URL displayed in your terminal.
